# Necesse - Spanish Translation (es)

Community project dedicated to improving the Spanish localization of [Necesse](https://store.steampowered.com/app/1169040/Necesse/).

## About This Project

This repository contains the Spanish localization file (`es.lang`) for Necesse, along with the original English file (`en.lang`) for reference.

The original Spanish translation is preserved in the Git commit history, allowing anyone to review, compare, and track improvements over time.

## Objectives

- Correct translation, spelling, grammar, and punctuation errors.
- Improve consistency across terminology, dialogue, and gameplay descriptions.
- Preserve the meaning and context of the original English text.
- Use natural, neutral Spanish suitable for players in both Spain and Latin America.
- Keep translations clear and concise while respecting UI space limitations.

## Testing Changes

Localization changes can be reloaded directly in-game using the following command:

`/reloadlang`
